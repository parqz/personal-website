# parsaghazvinian.com

This repository holds the content of Parsa Ghazvinian's personal website,
<https://parsaghazvinian.com>: his research, publications, CV and blog.

The site is built with [Jekyll](https://jekyllrb.com/) and served by GitHub Pages.
